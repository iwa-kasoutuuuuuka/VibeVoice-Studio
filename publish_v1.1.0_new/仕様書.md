# VibeVoiceStudio ネイティブ推論エンジン 仕様書

## 概要
本アプリケーションは、Hugging Face 上の VibeVoice モデル（Diffusion/Flow Matching ベースの自己回帰音声合成モデル）を、ONNX Runtime を用いて C# ネイティブ環境でローカル実行するためのポータブルな音声合成ツールです。

## 主な機能
1. **完全ネイティブ推論**:
   Python 等の外部ランタイムを必要とせず、`Microsoft.ML.OnnxRuntime` だけで 8 つの ONNX モデル群（言語モデル、Diffusion、Vocoder等）をシーケンシャルに自己回帰実行します。

2. **自動ダウンロードと管理**:
   初回起動時に、Hugging Face からモデル群（合計約 6GB）を自動で `models` ディレクトリにダウンロードし、適切に配置します。外部データ分離型の `.data` ファイルにも完全対応しています。

3. **C# ネイティブテキスト処理**:
   `Tokenizers.DotNet` を組み込み、Hugging Face の `tokenizer.json` (Qwen2/BPE) を用いて日本語・英語のテキストを直接トークン ID 配列に変換します。

4. **ゼロショット音声合成 (Zero-Shot TTS)**:
   任意の参照音声ファイル (WAV) を入力とし、`NAudio` によるダウンサンプリングと `MathNet.Numerics` による短時間フーリエ変換 (STFT) を用いて、80次元のメルスペクトログラムを自律抽出します。

## 実行環境
- **OS**: Windows 11 / Windows 10
- **依存**: 自己完結型 (Self-Contained) のため、.NET ランタイムの事前インストールは不要です。
- **ハードウェア**: 推論を高速化するため、DirectML / CUDA / TensorRT などを自動判定して使用します。

## トラブルシューティング
- **起動時エラー**:
  `models` フォルダ内の巨大なモデルファイルの一部が破損している場合、一度 `models` フォルダを削除してアプリを再起動し、再ダウンロードを行ってください。
- **UI フリーズ**:
  巨大なファイルのダウンロード処理はバックグラウンドで実行され、プログレス更新はスロットリング制御されているため、UI フリーズは発生しません。そのまま 100% になるまでお待ちください。
